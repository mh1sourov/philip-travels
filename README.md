# Philip Travels Landing Page

This project is a landing page for Philip Travels, a travel agency.  It is designed to capture user interest and encourage them to learn more or take action It is built using HTML and Tailwind CSS.

## Technologies Used

*   HTML
*   Tailwind CSS

## Features

*   Hero Section:A visually appealing section with a compelling headline, image/video, and a call to action.
*   Information Section:  A section providing key information about Philip Travels, its services, or travel destinations.
*   Call to Action: Clear and prominent call-to-action buttons or forms to encourage user engagement.
*   Contact Information:  Contact details for Philip Travels (e.g., phone number, email address, social media links).
